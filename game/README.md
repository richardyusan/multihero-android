# Game data goes here

The game's graphics, sounds and maps are **not** part of this repository.
Copy the contents of your original `MultiHero096` folder here (or pass its path to the build scripts):

```
game/
├── gfx/
├── sounds/
├── Maps/
├── game.cfg
├── keys.cfg
└── maps.dat
```

`.exe`, `.dll`, `.zip`, `.psd` and `.bat` files are ignored by the build. Everything in this folder
except this README is excluded by `.gitignore`.
